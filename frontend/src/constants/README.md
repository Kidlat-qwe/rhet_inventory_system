# Frontend constants

Shared option lists and category-behavior helpers used by inventory and category UI.

| File | Purpose |
|------|---------|
| `uniformOptions.js` | Category type / kind options, uniform gender·type·size lists, Freebies subtypes (`FREEBIE_*`), SKU helpers, and predicates (`isUniformCategory`, `isLearningKitCategory`, etc.). Freebie kinds mirror Uniform / Bundle inventory behavior. Freebie SKUs are prefixed with `FRE-` (e.g. `FRE-SCH-M-POLO-L`). |
