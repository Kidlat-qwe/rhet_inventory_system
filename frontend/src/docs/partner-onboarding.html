RHET Inventory System Partner onboarding

Partner onboarding overview

High-level steps for connecting an external system so it can request stock from RHET Inventory.

  1. RHET admin generates an API key on the API Keys page.
  2. Partner stores INVENTORY_API_URL and INVENTORY_INTEGRATION_KEY on their backend.
  3. Partner implements catalog fetch and stock-request create against /api/v1/integrations.
  4. Partner exposes an HTTPS webhook for RHET status callbacks (shipped / delivered / rejected, etc.).
  5. Smoke-test with a small request before production traffic.

Typical flow

Partner backend → POST /stock-requests with X-Integration-Key → RHET warehouse fulfills → RHET notifies partner webhook → partner confirms delivery when applicable.
